# Wiener Filter in This Project

This note explains:
- how Wiener filtering works in general,
- how it is used in this repository,
- what each related parameter in the code means.

Main implementation files:
- `utils/realtime_wiener.py`
- `tests/exp_hop_record_wiener.py`

## 1) What Wiener Filtering Does

Goal: estimate a clean signal `x[n]` from a noisy observation:

- `y[n] = x[n] + v[n]`

where `v[n]` is noise.

The Wiener filter is an MMSE estimator (minimum mean square error): it tries to minimize:

- `E[(x[n] - x_hat[n])^2]`

Intuition:
- where local signal power is strong relative to noise, keep details,
- where local noise dominates, smooth more aggressively.

So Wiener filtering is adaptive (not a fixed smoothing kernel everywhere).

## 2) How It Is Applied Here

In realtime processing (`BandpassWienerProcessor.process`), each audio block is processed per channel in two steps:

1. **Narrow band-pass**
   - Keeps only a target frequency band around `target_freq`.
2. **Wiener denoise**
   - Uses `scipy.signal.wiener(..., mysize=win_size)` on that band-limited signal.

So this pipeline is:

- `input -> band-pass -> Wiener -> output`

This is useful when you want one beacon-like frequency band while reducing noise inside that band.

## 3) Meaning of "Coefficients" in Your Code

Important clarification: your code has **two different filter mechanisms**.

### A) Band-pass filter coefficients (explicit, IIR SOS)

Generated by `design_bandpass_sos(...)` (Butterworth, SOS format).

Each SOS row is typically:
- `[b0, b1, b2, a0, a1, a2]`

These are the actual IIR coefficients used in streaming (`StreamingBandpassFilter`).

They are determined by:
- `sample_rate`
- `target_freq`
- `bandwidth_hz` (converted to `relative_margin`)
- `order`

### B) Wiener filter coefficients (implicit, adaptive)

For `scipy.signal.wiener`, you do **not** set fixed FIR/IIR coefficients manually.

Instead, SciPy computes local statistics in a window (`mysize`) and adapts filtering strength sample-by-sample:
- local mean,
- local variance,
- estimated noise power.

So in your code, the key "coefficient-like" control for Wiener is:
- `wiener_window` -> controls the local neighborhood size.

## 4) Parameter-by-Parameter Guide (Current Code)

Defined in `tests/exp_hop_record_wiener.py` and passed into `BandpassWienerProcessor`:

- `TARGET_FREQ_HZ = 8000.0`
  - Center frequency to keep.
  - Larger/smaller value shifts which tone band is preserved.

- `TARGET_BANDWIDTH_HZ = 1000.0`
  - Total passband width around center.
  - With 8 kHz center and 1 kHz bandwidth, band is roughly `7500..8500 Hz`.
  - Narrower = stronger isolation, but can miss drifted target.

- `FILTER_ORDER = 4`
  - Butterworth order for band-pass design.
  - Higher order = steeper cutoff, but higher complexity and more sensitivity.

- `WIENER_WINDOW = 31`
  - Local window length used by Wiener denoise (`mysize`).
  - Bigger window = stronger smoothing/noise suppression, but can blur fast changes.
  - Smaller window = preserves detail more, but less denoising.

- `sample_rate = 192000`
  - Sampling frequency.
  - Sets Nyquist limit and affects valid band design.

## 5) Derived Value in Code

In `utils/realtime_wiener.py`:

- `relative_margin = bandwidth_hz / (2 * target_freq)`

Then:
- `lowcut = target_freq * (1 - relative_margin)`
- `highcut = target_freq * (1 + relative_margin)`

This makes `bandwidth_hz` the intuitive tuning knob, while filter design still uses normalized margin internally.

## 6) Practical Tuning Tips

- If target tone is weak in heavy broadband noise:
  - increase `WIENER_WINDOW` moderately (e.g., `31 -> 41`).
- If target frequency drifts:
  - increase `TARGET_BANDWIDTH_HZ`.
- If nearby frequencies leak in:
  - increase `FILTER_ORDER` or reduce bandwidth.
- If output sounds over-smoothed:
  - reduce `WIENER_WINDOW`.

## 7) Why This Hybrid Design Is Useful

Pure Wiener on full-band audio may preserve unwanted frequency regions.
Pure narrow band-pass may still leave in-band noise.

Combining both gives:
- frequency selectivity (band-pass),
- in-band noise suppression (Wiener).
